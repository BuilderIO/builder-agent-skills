# Formulaic Structures to Break

## Binary contrasts ("not X, it's Y")

**Pattern:** "This isn't just a tool. It's a platform."

**Fix:** State what it is. "Tarsk routes requests to 27 providers."

**Pattern:** "The question isn't whether AI will change coding. It's how fast."

**Fix:** "AI coding tools ship weekly. Pick one that fits your workflow."

## Negative listings

**Pattern:** "No more manual config. No more context switching. No more vendor lock-in."

**Fix:** Name what the reader gets. "One API key reaches OpenRouter, Anthropic, and Google."

## Dramatic fragmentation

**Pattern:** "Fast. Reliable. Secure. Built for teams."

**Fix:** Write a sentence with a subject and verb.

## Rhetorical setups

**Pattern:** "What if you could run agents without sending code to a cloud VM?"

**Fix:** "Tarsk runs agents on your machine. Your repo stays local."

## False agency

**Pattern:** "The model understands your intent."
**Pattern:** "The architecture enables seamless scaling."
**Pattern:** "The update brings improved performance."

**Fix:** Name who does what. "You pick the model. Tarsk sends the request."

## Rule of three (overused)

Three parallel bullets or three adjectives in a row reads like a template. Use two when two suffice. Use four when you need four.

## Punchy paragraph closers

Every paragraph ending in a one-line zinger creates a metronome. End some paragraphs mid-thought, with a longer sentence, or with a concrete detail instead of a slogan.

## Wh- openers

"What makes this different?" "Why does this matter?" "How does it work?"

Restructure as statements unless the question is genuinely unanswered and central.

## Meta-joiners

"The rest of this section covers..."
"As we'll see below..."
"In the next part..."

Delete. Start the next section.

## Passive voice patterns

**Pattern:** "Errors are handled automatically."
**Fix:** "Tarsk retries failed tool calls."

**Pattern:** "The feature was designed to reduce latency."
**Fix:** "We cut round-trip time by caching provider catalogs locally."

## Vague declaratives

**Pattern:** "The implications are significant."
**Fix:** "You pay per token. A 1M context window costs 4x on most providers."

**Pattern:** "The approach is structurally sound."
**Fix:** "MoE models activate 3B of 30B parameters per token."

## Em dashes

Replace with commas, periods, or parentheses. Do not use em dashes.
